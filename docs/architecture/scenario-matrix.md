# 真实数仓任务评审与测试矩阵

每个案例记录：业务任务目标；实体/模型版本；使用者身份；所需能力；实体和关系约束；数据/物理来源；编译/执行计划；证据；预期结果/拒绝；缺口责任；回归。

| ID | 真实问题或变更 | 验收门槛 | 阶段 |
|---|---|---|---|
| S01 | 最近 7 天 DAU 按 App 版本 | 口径、时间、去重和多版本用户的可加性正确 | F2 |
| S02 | DAU 按“年龄” | 注册/实名/推断年龄有歧义且按权限处理 | F2 |
| S03 | 只有每天 DAU，请算七日去重 | 不能直接相加，说明原始事件依赖 | F2 |
| S04 | 有已认证事件明细，请算七日去重 | 正确生成有界 DISTINCT 推导与证据 | F3 |
| S05 | DWS 从用户日变为用户日版本粒度 | 发现指标、特征和下游模型 Breaking 风险 | F3 |
| S06 | 数据分区未完成 | NOT_READY，不回答成 0 或无记录 | F3 |
| S07 | 有回补后的历史事件数据 | 不把事后可得数据当成当时已知特征 | F5 |
| S08 | 库存余额按天统计 | 半可加选择 LAST，而不是直接 SUM | F4 |
| S09 | 明细跨表多对多 | 无认证桥接路径则拒绝或限缩 | F4 |
| S10 | 人工认证 SQL 和 BI 一致，埋点漏报 | 不能宣称已证明现实业务真值，标明外部证据缺口 | F3 |
| S11 | 实时任务延迟 | 从 Flink/调度等观测提供证据；不知道根因就说未知 | F3 |
| S12 | 同名“新增用户”跨业务域 | 返回明确候选或依据授权默认选用 | F2 |
| S13 | 未授权访问实名年龄 | 拒绝/隐藏敏感资产；严防通过关联侧漏 | F2 |
| S14 | 历史 BI 查询回放 | 绑定语义发布、物理快照、策略及可用数据时间 | F3 |
| S15 | 外部 Agent 将正确查询结果错误解释 | 仅标记 AWE 工具结果验证，不能自动计算整体任务成功 | F3 |
| S16 | 来源有数据但平台未编目录 | UNKNOWN，不宣称企业不存在 | F1 |
| S17 | 重复失败提示缺少维度关系 | 同一 Gap 聚合、人工确认、修复和回归 | F3 |
| S18 | Agent 触发数千个昂贵探索查询 | 有预算、并发、缓存/预计算或拒绝路径 | F4 |
| S19 | 生产加工变更但语义文件未改 | 检测物理/契约漂移并阻断破坏性发布 | F3 |
| S20 | 算法离线特征与在线特征偏差 | 明确时点、TTL、回补、版本和对账 | F5 |

建议首轮与业务数仓共同评审 S01—S06、S10—S12；以 S07、S08、S16 验证是否错误锁定了未来扩展。
