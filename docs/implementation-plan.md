# AWE 实施路线：从成熟域可信消费进入生产准入

依据 [产品路线](roadmap.md)、[ADR-015](architecture/adr-015-domain-knowledge-and-controlled-consumption.md) 与 [ADR-016](architecture/adr-016-data-task-and-responsibility-boundaries.md)。以当前 `main` 为基线复用七类内核、Registry、发布、来源与检查能力，不另建 Agent 或原型。

## 交付顺序与退出条件

| 增量 | 实施内容 | 可运行验收 | 边界与后续 |
|---|---|---|---|
| M0 领域基线，随接入持续开展 | 已有资产、正式语义、所有权、来源/覆盖、真实问题与独立参考；标记未纳管入口 | 能说明某个任务需要哪些正式定义、可信来源和责任方；未知与歧义如实保留 | 企业资产与连接由领域团队线下接入；工程测试不替代领域验收 |
| M1.1 受控 Dataset 真实取数，本轮工程 | 注册只读 Function；固定 Dataset 与独立输出行 Schema；独立消费身份；显式投影/时间范围/用途/预算；原生 PostgreSQL 元数据和真实行读取；持久证据及工作台 | 发布模型→消费发现→受权请求→当前来源复检→真实取数→类型化结果与快照；覆盖越权、错误版本、漂移、空集、超限和幂等反例 | 仅显式引用解析；当前事务可见范围，不保证账期完整；不包含指标问数、任意 SQL、Join 或通用工作流 |
| M1.2 已有可信 BI/指标 DIRECT 消费 | 正式指标消费契约，单位/统计对象/固定口径与时间参数；版本化外部实现；BI/指标适配、真实就绪观测、状态及独立对账 | 同一发布定义调用已有可信实现，在相同账期/数据范围与独立参考一致；未到齐/未配置不返回 0 | 复用既有指标计算，不要求重写全部 SQL；Schema 合法不冒称数值已验证 |
| M1.3 通用语义解析与受限组合 | 按域验收集补身份规则适用性、时间/事件、人群、合法关联、集合/窗口及聚合；召回/消歧；有界 Semantic IR | 真实任务可直接提供或给出可验证推导；非法路径、歧义、缺口/未知与数据问题分别处理；原任务回归 | 不为十道题硬编码十条流程；跨历史规则、去重及数据覆盖是算子前提；未支持明确拒绝 |
| M1 业务准入与默认链路 | 真实身份/委托、域/行列/用途策略、来源端授权、成本/延迟、结果保留与导出治理；保留集与影子运行；失败归因及外部修复回归 | 领域负责人接受约定任务与反例；支持覆盖和正确拒绝分别统计；受控适配与例外直连分别记录 | 服务 Token、参考 PostgreSQL、CI 和当前只读检查不能单独满足生产门槛 |
| M2 本域新增/变更准入 | Pipeline 输入输出/加工意图、代码制品与模型绑定；传递/共享资产影响；受影响回归与现有发布端收据检查 | 错制品、过期批准、漂移或不充分回归不能沿实际部署链发布；真实修复能按原义务重验 | Agent/开发平台仍负责修改、调试、作业、发布及回滚；AWE 不接管工程控制流 |
| M3 逐域复制 | 下一成熟域重复资产基线→可信消费→新增准入；管理跨域所有权、口径与合法关联 | 第二个域不靠新增问题专属内核代码完成接入；跨域能力独立验收 | 按需要提前建设 F4/F5，不能用错误简化计算替代 |

M1.2 与 M1.3 按首个领域的真实资产条件调整局部顺序；已有可靠 DIRECT 能力优先。每个增量应形成可运行接口、正反例、证据和文档，不能以协议名称或页面完成宣称整个 M1/F3 已完成。

## 本轮实现的设计约束

1. DataTask v1 只支持 `EXTRACT` 与 `OBSERVED_SNAPSHOT`。外部 TaskRef 仅关联，服务端独立产生操作 ID；不承载完整任务、工具循环或业务成功状态。
2. 消费候选是 Function 的精确 Release/Hash。服务端读取不可变清单，固定 Dataset、输出行 Schema 及业务主体，校验执行签名；不根据名称猜测能力。
3. 输出行 Schema 显式使用 `ObjectType(DATASET)`，不把 Dataset 的业务 subject 当成所有物理字段。首版采用具名版本执行签名约定的同名列映射，不隐式 Join。
4. 只读 PostgreSQL 是本轮真实执行源，标识为 `postgres`。Hive/BI 继续走各自真实适配；未配置不冒称已经接入。元数据来源与实际取数指向同一服务端资产映射。
5. 独立消费策略限制 Function、列、用途、时间范围、返回行数及行数据字节；作者/审核身份不自动拥有数据读取权，当前不支持敏感字段与行级策略。
6. 半开事件时间区间必须显式提供带偏移的时刻；不猜“昨天”“最新账期”或全局 T-1。空集表示当前观测范围无匹配记录，不等于零指标或账期完成。
7. 固定预算内完整取数才能返回结果；超限不静默截断、过滤未知要求或返回部分行冒称完整。原生事务快照是本次读取证据，不是历史恢复能力。
8. 结构检查、独立对账、数据到齐及业务验收分开；修复仍由领域团队、外部 Agent 与既有平台执行。

具体运行范围见 [ADR-017](architecture/adr-017-controlled-dataset-consumption.md)；接口与配置见 [Registry 运行说明](../awe-registry/README.md)。
