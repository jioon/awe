# AWE 实施路线：从成熟域可信消费进入生产准入

依据 [产品路线](roadmap.md)、[ADR-015](architecture/adr-015-domain-knowledge-and-controlled-consumption.md) 、[ADR-016](architecture/adr-016-data-task-and-responsibility-boundaries.md) 与 [ADR-018](architecture/adr-018-executable-capabilities-and-production-admission.md)。以当前 `main` 为基线复用七类内核、Registry、发布、来源与检查能力，不另建 Agent 或原型。

## 交付顺序与退出条件

| 增量 | 实施内容 | 可运行验收 | 边界与后续 |
|---|---|---|---|
| M0 领域基线，随接入持续开展 | 已有资产、正式语义、所有权、来源/覆盖、真实问题与独立参考；标记未纳管入口 | 能说明某个任务需要哪些正式定义、可信来源和责任方；未知与歧义如实保留 | 企业资产与连接由领域团队线下接入；工程测试不替代领域验收 |
| M1.1 受控 Dataset 真实取数，已交付 | 注册只读 Function；固定 Dataset 与独立输出行 Schema；独立消费身份；显式投影/时间范围/用途/预算；原生 PostgreSQL 元数据和真实行读取；持久证据及工作台 | 发布模型→消费发现→受权请求→当前来源复检→真实取数→类型化结果与快照；覆盖越权、错误版本、漂移、空集、超限和幂等反例 | 仅显式引用解析；当前事务可见范围，不保证账期完整；不包含指标问数、任意 SQL、Join 或通用工作流 |
| M1.2 已有可信 BI/指标 DIRECT 消费，工程已交付 | 正式指标消费契约，单位/统计对象/固定口径与时间参数；版本化外部实现；BI/指标适配、真实就绪观测、状态及独立对账 | 同一发布定义调用已有可信实现，在相同账期/数据范围与独立参考一致；未到齐/未配置不返回 0 | 复用既有指标计算，不要求重写全部 SQL；Schema 合法不冒称数值已验证 |
| M1.3 正式能力解析与受限组合，受支持范围已交付 | 正式身份/时间/单位/粒度、认证关联、集合/窗口/聚合 IR；正式名和审定别名检索/消歧；复杂历史身份按域扩展 | 真实任务可直接提供或给出可验证推导；非法路径、歧义、缺口/未知与数据问题分别处理；原任务回归 | 不为十道题硬编码十条流程；跨历史规则、去重及数据覆盖是算子前提；未支持明确拒绝 |
| M1 业务准入与默认链路 | 真实身份/委托、域/行列/用途策略、来源端授权、成本/延迟、结果保留与导出治理；保留集与影子运行；失败归因及外部修复回归 | 领域负责人接受约定任务与反例；支持覆盖和正确拒绝分别统计；受控适配与例外直连分别记录 | 服务 Token、参考 PostgreSQL、CI 和当前只读检查不能单独满足生产门槛 |
| M2 本域新增/变更准入，工程与真实参考平台已交付 | Pipeline 输入输出/加工意图、代码制品与模型绑定；传递/共享资产影响；受影响回归与现有发布端收据检查 | 错制品、过期批准、漂移或不充分回归不能沿实际部署链发布；真实修复能按原义务重验 | Agent/开发平台仍负责修改、调试、作业、发布及回滚；AWE 不接管工程控制流 |
| M3 逐域复制 | 下一成熟域重复资产基线→可信消费→新增准入；管理跨域所有权、口径与合法关联 | 第二个域不靠新增问题专属内核代码完成接入；跨域能力独立验收 | 按需要提前建设 F4/F5，不能用错误简化计算替代 |

M1.2 与 M1.3 按首个领域的真实资产条件调整局部顺序；已有可靠 DIRECT 能力优先。每个增量应形成可运行接口、正反例、证据和文档，不能以协议名称或页面完成宣称整个 M1/F3 已完成。

## 当前工程交付与真实验收

M1/M2 受支持范围已贯通，不代表企业部署或所有问题类型均已验收。领域资产、IdP、Hive/Spark/BI/调度及实际准入入口由用户线下接入；代码提供稳定适配协议、真实数据库参考与拒绝语义。

| 能力 | 当前可运行行为 | 回归证据 |
|---|---|---|
| 正式计算定义 | v3 Dataset/Metric/Pipeline facet；严格类型、单位声明、输入身份、时间角色、输出粒度；v2 不可变发布兼容 | 内核与编码/兼容反例 |
| 真实消费 | v1 EXTRACT；v2 QUERY_METRIC；原生 PostgreSQL 编译 IR 与版本绑定 BI DIRECT；完整预算；空集/0/NULL/未就绪分开 | 独立 SQL 比较、错误聚合、集合/窗口/分组/比率、Join 唯一性、源行预算 |
| 当前授权 | OIDC/委托与服务端允许范围；列、用途、真实扫描窗口、每个源强制行过滤；政策变更隐藏历史结果 | 真实 RSA JWT、原生行过滤、SQL 条件值注入反例、旧结果撤权 |
| 知识与证据 | 审定覆盖、正式名/别名/候选确认/歧义；不可变分阶段观测；REST/MCP 共用能力服务 | 未命中 UNKNOWN、授权隔离、错误工具与假缺失反例 |
| 修复重验 | 用户反馈、维护者分类、独立受审参考、同范围回放与模型修订替代验收；正确拒绝/未就绪回归；重复/复发记录 | 不同时间/权限/物理范围不能关闭原问题；Agent 总体错误不自动关闭 |
| 实现准入 | 逻辑目标先行；规范 Pipeline 制品；完整传递和共享物理影响；真实候选/独立回归；短期在线一次收据 | 错字节、删义务、伪造 PASSED、陈旧/实际过期批准、影响变化、并发消费 |
| 物化与再消费 | 外部参考平台按全部共享物理目标版本/写意图原子 CAS 建表，AWE 独立观测部署/元数据并绑定 Dataset/Schema/制品/run/attempt；下游使用确切物化 | 真实新表可查询；新写许可先封旧绑定；实时复核活动版本；跨 Pipeline 迟到发布和旧回调不能绕过；同 Schema 语义替换不能借旧证明 |
| 工作台与 CI | 指标消费、知识/反馈和生产准入页面；Flyway V6—V10；格式与真实 PostgreSQL/HTTP 回归 | 页面只调用真实接口，不内置成功数据；CI 不允许跳过集成测试 |

## 保持的约束与尚未验收部分

1. DataTask 是轻量数据操作协议；外部 TaskRef 仅关联，不承载通用任务、Skill、工具循环或全局业务成功。
2. 七类模型及严格 v2 继续有效；v3 契约不改写旧 Release/Hash。输出行 Schema 不等于业务 subject。
3. 模型固定计算，用户不能换 SQL/IR；权限由可信身份和服务端政策决定。就绪证明覆盖真正扫描的窗口/静态快照，不能只证明结果日。
4. 现有平台负责执行、CAS 部署和回滚。AWE 不做调度器或代码工作区；任意 SQL/脚本不能取得通用语义等价认证。
5. 结构合法、独立对账、人工参考回归、账期到齐、业务验收分别记录。事务快照 Hash 不是历史恢复能力。
6. 通用量纲推导/单位换算、AS_OF/SCD、多对多、复杂历史身份合并、任意自然语言分析等仍需按域扩展，未支持明确拒绝；本轮没有宣称 F4—F6 完成。
7. 企业端应验证来源真实授权、写入与旁路治理、生产准入强制执行、容量/时延、保留/导出与容灾。参考平台或 CI 不能替代这些验收。

后续先完成线下首域 M0/保留集映射与协议接入，验证支持和正确拒绝，再决定该域默认入口切换。M2 真正生效依赖外部发布端在线消费和 CAS；M3 在第二个域验证可复制性，不能靠第一域测试自动推定。

配置与接口见 [消费/知识能力](../awe-registry/CAPABILITIES.md)、[身份](../awe-registry/IDENTITY.md)、[生产准入](../awe-registry/PRODUCTION.md)。完整架构与取舍保留在 ADR-013—020。

## 下一工程增量

共享目标加固见 ADR-019，模型替代和结局回归见 ADR-020。本轮已完成受审旧问题→修订模型→新参考义务与实际替代验收，以及 DATA_OUTCOME 负例期望/观测/回放；保留旧 caseHash 和精确 scope 闭合。

M1/M2 **仍不标记完整完成**。后续优先推进结构化主体/指标/维度/筛选/人群/时间需求到服务端合法计划与供给裁决，补首域必需身份/事件/时间规则；完善版本停用和消费者切换治理；建设 REGISTERED_EXTERNAL 存量 SQL/制品的具名有限证明准入，以及实际生产依赖覆盖。企业首域接入并行线下开展，不用固定 Function 目录或外部 Skill 硬逻辑代替这些能力。
